## 程式目錄

- `apps/api/src/app.ts`：Fastify HTTP 邊界；身份、CSRF、Web 使用者生命週期與能力授權、連線、瀏覽、SQL、資料異動、DDL 與 SSH TOFU reset routes。
- `apps/api/src/runtime.ts`、`server.ts`：環境設定、依賴組裝、bootstrap admin、排程器與程序生命週期。
- `apps/api/src/auth/`：Argon2id 使用者、session、停啟/角色/密碼/刪除生命週期、最後可用管理員保護與記憶體測試 repository。
- `apps/api/src/access/`：每 connection 六項 Web capability、相依能力閉包、可見連線與逐請求授權。
- `apps/api/src/security/`：AES-256-GCM envelope encryption 與 365 天 Web/原生帳號、授權及憑證驗證安全事件。
- `apps/api/src/accounts/`：PostgreSQL role/MySQL user@host 正規化與保護政策、用途綁定憑證 vault、原生帳號生命週期、跨 database grant/revoke planner與方言gateway、每 connection 五並行背景驗證及四版本 integration test。
- `apps/api/src/metadata/`：Kysely SQLite/PostgreSQL schema 與身份、Web 授權、連線、稽核、保活 repositories。
- `apps/api/src/connections/`：加密連線設定、PG/MySQL TLS/TCP connector 與 SSH socket 注入邊界。
- `apps/api/src/ssh/`：SSH2 transport adapter、共享 tunnel pool、SHA-256 TOFU pin 與 reset audit domain。
- `apps/api/src/database/`：PG/MySQL 唯讀 schema、table、column 與分頁 row gateway。
- `apps/api/src/data/`：已完成的 M3A；tagged database value、穩定列鍵與可寫能力、交易式資料異動 service、PG/MySQL mutation gateway、加密異動稽核及四版本真實資料庫 integration test。
- `apps/api/src/ddl/`：M3B/M3C DDL；版本化 capability、核心與進階物件 command、型別/選項/片段白名單、PG/MySQL SQL builder與gateway、管理員 service、加密稽核及四版本 integration test。進階範圍含view、routine、trigger、partition及各方言專屬物件；MySQL routine characteristics以結構化 deterministic/data-access選項產生，不接受任意token。
- `apps/api/src/query/`：多語句 SQL、上限、逾時、取消、高風險確認、唯讀語句分類及 dialect readonly transaction gateway。
- `apps/api/src/audit/`：SQL 憑證遮蔽、加密與 90 天保存。
- `apps/api/src/keepalive/`：SQL `SELECT 1` 排程、逾時隔離與事件保存。
- `apps/api/src/transfers/`：M5 transfer job 狀態與配額、用途綁定分段加密暫存、續傳/整檔 checksum、preview token與orchestration、安全串流下載、retention scheduler及90天加密audit；CSV/JSON/SQL格式引擎由後續子里程碑注入 inspector/processor。
- `apps/web/src/`：React/Vite 雙語管理工作台；登入/強制改密碼、Web 使用者生命週期與六能力矩陣、原生帳號生命週期/單次密碼查看/實際grant讀取及分層grant/revoke、直連/SSH 連線、資料瀏覽與 capability 驅動 CRUD/批次更新、SQL 執行/取消、36 項核心與進階 DDL 結構工作台、transfer job與8 MiB續傳上傳/下載、高風險確認及 TOFU reset。
- `e2e/`、`playwright.config.ts`：Chromium/Firefox/WebKit 核心流程與桌面/手機版面 smoke。
- `Dockerfile`、`compose.yaml`、`.env.example`：非 root production image、SQLite volume 與部署環境契約。
- `README.md`：Windows 本機、production build、Docker 與驗證指令。
- `.github/workflows/ci.yml`：品質、三瀏覽器、Docker image 與 PostgreSQL/MySQL 版本矩陣驗證；MySQL routine 測試由 root 設定測試專用 `log_bin_trust_function_creators=1`，原生帳號測試則明確給受保護 `dbweb` 管理連線 `CREATE USER ... WITH GRANT OPTION` 及 `mysql.user`、`mysql.db`、`mysql.tables_priv` 的最小目錄讀取權限。實際 DDL、帳號與 grant 操作仍由該非 root 連線執行，受管帳號不取得管理權限。
- 根目錄 `package.json`、`pnpm-workspace.yaml`、`tsconfig.base.json`、`vitest.config.ts`、`eslint.config.mjs`：monorepo 工具鏈與共用品質指令。

## 依賴方向

- HTTP/runtime 依賴 domain service；domain service 只依賴 repository/gateway interface；Kysely 與 PG/MySQL driver 實作位於外圍 adapter。
- 敏感連線設定只經 `ConnectionService.resolveConnection()` 於後端內部解密，公開 API 僅回傳非敏感 profile。
- SQL 查詢與 keepalive 共用 dialect gateway，稽核及保活事件只透過 metadata repository 持久化。
- SSH transport pool 由 runtime 單例持有，透過 `DatabaseSocketProvider` 注入所有 PG/MySQL 操作；公開 profile 不含 SSH 密碼，TOFU reset audit 不含 host key。
- 資料異動由 `DataMutationService` 統一執行管理員授權、能力檢查、批次上限與稽核；dialect gateway 在單一交易內執行參數化 SQL，並以穩定唯一鍵及原始值偵測衝突。
- 核心與進階 DDL 由 `DdlService` 先取得真實伺服器版本並套用 capability 白名單，再交由方言 gateway 執行；程式碼物件原文只進入加密 SQL templates，PG/MySQL 的交易能力差異不被抽象隱藏。
- `WebAccessService` 以 metadata 為即時真相；HTTP 邊界先阻擋未授權請求，`SqlQueryService`/`DataMutationService`/`DdlService`再執行各自的唯讀或能力防護，避免只依賴 UI 或單層route檢查。
- Web 使用者角色、啟用狀態與密碼變更由 `AuthService` 統一撤銷全部 sessions；Kysely repository 以 lifecycle lock 序列化最後可用管理員檢查，安全事件只保存非敏感索引與加密details。
- 原生帳號以資料庫實際狀態為真相，metadata 只保存受管狀態、用途綁定密文與驗證排程；`NativeAccountService` 每次重新讀取帳號以保護 connection/system identity，`NativeAccountVerifier` 透過相同 TLS/SSH gateway 驗證指定 database。
- 跨 database 權限由 `NativeGrantService` 重新讀取實際帳號並套用方言/層級白名單；PostgreSQL 以目標 database 暫時連線執行交易，MySQL 以完整限定名稱逐步執行並保留 partial failure，SQL templates只進加密security audit details。
- transfer HTTP/runtime 只接受受控job狀態與逐請求Web capability；來源/輸出chunk store以job/index及source/output namespace綁定密文，job repository以CAS防止平行chunk進度倒退，cleanup只有在所有artifact刪除成功後才移除到期metadata/audit。
- production Fastify 可供應 `apps/web/dist`，未知非 API GET route 回 SPA index；`/api/*` 維持 JSON 404。
