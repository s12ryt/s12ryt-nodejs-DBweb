## 程式目錄

- `apps/api/src/app.ts`：Fastify HTTP 邊界；身份、CSRF、連線、瀏覽、SQL、資料異動、核心 DDL 與 SSH TOFU reset routes。
- `apps/api/src/runtime.ts`、`server.ts`：環境設定、依賴組裝、bootstrap admin、排程器與程序生命週期。
- `apps/api/src/auth/`：Argon2id 使用者、session 與記憶體測試 repository。
- `apps/api/src/security/`：AES-256-GCM envelope encryption。
- `apps/api/src/metadata/`：Kysely SQLite/PostgreSQL schema 與身份、連線、稽核、保活 repositories。
- `apps/api/src/connections/`：加密連線設定、PG/MySQL TLS/TCP connector 與 SSH socket 注入邊界。
- `apps/api/src/ssh/`：SSH2 transport adapter、共享 tunnel pool、SHA-256 TOFU pin 與 reset audit domain。
- `apps/api/src/database/`：PG/MySQL 唯讀 schema、table、column 與分頁 row gateway。
- `apps/api/src/data/`：已完成的 M3A；tagged database value、穩定列鍵與可寫能力、交易式資料異動 service、PG/MySQL mutation gateway、加密異動稽核及四版本真實資料庫 integration test。
- `apps/api/src/ddl/`：M3B 核心 DDL capability、版本化型別/選項白名單、database/schema/table/column/index/constraint 方言 SQL builder、PG/MySQL gateway、管理員 service、加密稽核與四版本 integration test。
- `apps/api/src/query/`：多語句 SQL、上限、逾時、取消、高風險確認與 dialect gateway。
- `apps/api/src/audit/`：SQL 憑證遮蔽、加密與 90 天保存。
- `apps/api/src/keepalive/`：SQL `SELECT 1` 排程、逾時隔離與事件保存。
- `apps/web/src/`：React/Vite 雙語管理工作台；登入、直連/SSH 連線與使用者管理、資料瀏覽與 capability 驅動 CRUD/批次更新、SQL 執行/取消、核心 DDL 結構工作台、高風險確認及 TOFU reset。
- `e2e/`、`playwright.config.ts`：Chromium/Firefox/WebKit 核心流程與桌面/手機版面 smoke。
- `Dockerfile`、`compose.yaml`、`.env.example`：非 root production image、SQLite volume 與部署環境契約。
- `README.md`：Windows 本機、production build、Docker 與驗證指令。
- `.github/workflows/ci.yml`：品質、三瀏覽器、Docker image 與 PostgreSQL/MySQL 版本矩陣驗證。
- 根目錄 `package.json`、`pnpm-workspace.yaml`、`tsconfig.base.json`、`vitest.config.ts`、`eslint.config.mjs`：monorepo 工具鏈與共用品質指令。

## 依賴方向

- HTTP/runtime 依賴 domain service；domain service 只依賴 repository/gateway interface；Kysely 與 PG/MySQL driver 實作位於外圍 adapter。
- 敏感連線設定只經 `ConnectionService.resolveConnection()` 於後端內部解密，公開 API 僅回傳非敏感 profile。
- SQL 查詢與 keepalive 共用 dialect gateway，稽核及保活事件只透過 metadata repository 持久化。
- SSH transport pool 由 runtime 單例持有，透過 `DatabaseSocketProvider` 注入所有 PG/MySQL 操作；公開 profile 不含 SSH 密碼，TOFU reset audit 不含 host key。
- 資料異動由 `DataMutationService` 統一執行管理員授權、能力檢查、批次上限與稽核；dialect gateway 在單一交易內執行參數化 SQL，並以穩定唯一鍵及原始值偵測衝突。
- 核心 DDL 由 `DdlService` 先取得真實伺服器版本並套用 capability 白名單，再交由方言 gateway 執行；SQL templates 加密保存，PG/MySQL 的交易能力差異不被抽象隱藏。
- production Fastify 可供應 `apps/web/dist`，未知非 API GET route 回 SPA index；`/api/*` 維持 JSON 404。
